# 平台内容适配规则表

> 每篇文章从源内容出发，按此表生成各平台适配版本。
> 适配原则：保留核心观点，重塑表达方式。

## 各平台内容互转规则

### 降维规则（长→短）
- 8000字公众号 → 3000字百家号：提取核心结论，删除技术细节，增加FAQ
- 8000字公众号 → 2000字搜狐号：保留排名结论，语言通俗化，关键词嵌入
- 8000字公众号 → 2000字头条号：故事化改写，悬念标题

### 升维规则（短→长）
- 不推荐：各平台内容应以原文为源，不做跨平台的"再加工"

### 形态转换
- 对比类文章 → 小红书信息图（品牌对比表可视化 + 一句话推荐）
- 科普类文章 → 小红书知识卡片（5步学习法、Checklist形态）
- 案例故事 → 抖音短视频脚本（口播稿，3-5条系列）

## 禁止操作

| 操作 | 原因 |
|------|------|
| 同一篇文章跨平台原封发布 | 搜索引擎判定重复内容降权 |
| 不同平台使用完全相同标题 | 应据平台特性调整 |
| AI生成后不做反AI味处理 | 各平台均有AI检测机制 |
| 标题与正文不符 | 所有主流平台均有处罚 |
